## Sobre o Projeto

Este projeto é um portfólio/carrossel interativo focado em design UI/UX. Ele permite que o usuário navegue por diferentes modelos de carros de luxo com animações de transição suaves. A aplicação foi pensada com a mentalidade **Mobile-First**, garantindo que a experiência em dispositivos móveis seja tão impressionante quanto no desktop.

A ideia base surgiu de um desafio de "Projeto Criativo", onde exploramos propriedades avançadas do CSS (como cálculos usando variáveis) para rotacionar e animar os elementos na tela de forma coordenada usando JavaScript puro.

## Funcionalidades

- **Animações Coordenadas:** O clique nas setas dispara transições complexas onde o carro gira, entra na tela e os textos (títulos e descrições) deslizam em sequência com diferentes *delays*.
- **Design Responsivo:** A interface se adapta perfeitamente a telas menores, reorganizando o layout para melhor usabilidade.
- **Menu Glassmorphism:** Em dispositivos móveis, a barra de navegação tradicional é substituída por um elegante menu lateral com efeito "vidro" (desfoque e transparência) ativado por um ícone de hambúrguer.
- **Efeitos de Hover:** Botões e links de navegação possuem interações dinâmicas que incentivam o clique (mudanças de cores e brilho).

## Tecnologias Utilizadas

O projeto foi construído puramente com as linguagens base da web, sem o uso de frameworks externos:

- **HTML5** - Estruturação semântica
- **CSS3** - Estilização avançada, CSS Nesting, Variáveis CSS (`var()`, `calc()`), Flexbox, CSS Grid, Transições e Media Queries
- **JavaScript (Vanilla)** - Lógica de manipulação do DOM e controle do estado ativo/inativo das animações
